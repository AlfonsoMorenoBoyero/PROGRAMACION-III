# **Programación III - _Semana 1_**

## Primeros pasos con Java, VSCode, Giy y Github.
### _Repositorio de las prácticas de la primera semana (1<sup>a</sub> semana)._


##  Ejercicios de la Semana 1

1. **`HolaMundo.java`**: Programa para escribir Hola, mundo! por pantalla.
2. **`Suma.java`**: Programa para solicitar dos números por teclado y sumarlos.
3. **`Prueba.java`**: Programa para compilar y ejecutar desde la terminal mediante distintos comandos.
4. **`Mayor.java`**: Programa que calcula el mayor de entre tres números introducidos por el usuario.
